Chapter 04 · Documents

Create it. Sign it. File it.

Safeshield Secure is our document standard: protected client upload, smart document preparation, human review, e-signing, completed delivery, and permanent audit evidence.

The new standard

Safeshield Secure is our e-sign provider.

Do not use NowCerts document signing. Every e-signature and every sensitive-document request should go through Safeshield Secure, with the protected link sent instead of the attachment.

A major new capability

Put the signing link inside the email you are already sending.

Safeshield Secure can give you a real web link for the client’s signing session. If you are writing a welcome email but still need the old-policy cancellation signed, include the signing button in that same message. The client gets one clear experience, and you do not have to wait for a separate signing email before moving forward.
