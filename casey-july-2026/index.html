Safeshield Secure

Send documents as links, not attachments. This is now how we send anything with a client's name and policy number on it: dec pages, ID cards, proposals, loss runs, P&Ls.

Live now

New item in the left nav. Pick a file, add the recipient, and write one line on why you're sending it. CASEY drafts the subject and message from there, and you edit before it goes. The client gets a link that expires, 7 days by default, up to 90.

2CASEY drafts itSubject and message, you edit before it goes
3Client gets a linkExpires in 7 days by default
4A code hits their inbox6 digits, once per device, remembered 30 days
5You watch it landOpens, downloads, and real reading time

Why the code matters. A link that leaks or gets forwarded is worth nothing without control of their inbox. It is asked once per device, then remembered for 30 days, so it is not a nuisance for them and there is nothing for you to share.

The one setting worth thinking about

Download on

They can save the file. Right for an ID card or a dec page they need to keep.

Download off

View only. The original file never reaches their browser at all. CASEY renders the pages as images watermarked with their email and the date. Right for a proposal, or anything you don't want circulating.

PDFs open in a reader with the sections listed down the left, so a long proposal is navigable instead of an endless scroll.

Copying people

Add anyone under "Also send to." Everyone named gets their own link, own code, and own tracking, so "did the client open it" and "did Eric open it" stay separate answers, and cutting one person off doesn't touch anyone else. Copy me is on by default so a record lands in your own inbox.

Then check "Sent documents"

Recipient, status, opens, downloads, expiry, and time actually spent reading, which is the number that tells you whether a proposal was read or just opened. It only counts while the tab is in front of them, so a document left open overnight doesn't come back as eight hours of interest.
